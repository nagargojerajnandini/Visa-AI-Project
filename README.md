# Visa-AI-Project

##  Project Title
AI Enabled Visa Status Prediction and Processing Time Estimator

##  Project Description
This project uses Machine Learning to predict:
- Visa Approval Status (Approved / Rejected)
- Estimated Visa Processing Time (in days)

The model is trained using a structured visa application dataset containing applicant details such as income, education, travel history, documents status, interview score, etc.

2. Load the dataset (visa_dataset.csv)
3. Run all cells in order

##  Project Outcome
The model successfully predicts visa approval status and estimates processing time with good accuracy. This project demonstrates practical implementation of Machine Learning in real-world immigration data analysis.
